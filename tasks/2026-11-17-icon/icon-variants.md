- 作成: 蒙恬（2026-11-17）
- 裁定: `docs/user-decisions.md` の「裁定（2026-11-17、アイコン・日本語化・拡張の足し方）」。アイコンは、Claude のアイコンと VS Code のアイコンを合わせた意匠にする。名称の文字は絵に入れない。前提は個人利用で、商標の扱いは確かめていない。

## 2. 共通の作り

- 元の絵は2つ。どちらもリポジトリの中の写し（`scripts/icon-src/`）から描く。
  - VS Code: 公式の 1.146.0 の `code-icon.svg`（256 の座標）。奥の折り目 `#0065A9`・手前の折り目 `#007ACC`・右の柱 `#1F9CF0` の3枚を外形で切り抜き、上に白の光沢（不透明度 0.25、上から下へ消える、重ね方は overlay）を重ねる。これは元の SVG と同じ。元の SVG にある影（ぼかしの filter）は描いていない。
  - Claude: Claude Code 拡張 2.1.322 の `claude-logo.svg`（24 の座標、色 `#D97757`）。形と色はそのまま使う。
- 座標は 1024×1024 で組み、PNG と ICO は台本が描く。SVG は、元のパスに位置と倍率（`matrix`）を付けて組む。
- 2つの絵が重なる所は、上の絵のまわりに隙間を作る（A・B は透かし、C は板の色で縁取る）。小さい大きさで2つが溶け合わないようにするため。
- 透かし（`letterpress-*.svg`）は1色の影絵。大きさ 260×260・不透明度（明るい 0.1、暗い 0.3）・ハイコントラストの色（`#D9D9D9`・`#3C3C3C`）は今のファイルと同じ。

## 3. 候補

### A 中央に印（`center-spark`）

VS Code の青いリボンを全面に置き、真ん中に Claude の橙の印を重ねる。VS Code が主で、Claude が真ん中の印。

- 置き方（1024 の座標）: リボンは 64〜960。印は幅 480 で、中心 (600, 512)。リボンの切り欠き（三角の穴）を覆い、2本の腕の付け根と右の柱に少しかかる。
- 色: リボンは VS Code の元の3色、印は `#D97757`。印のまわりに幅 28 の隙間（透明）。
- 小さい大きさ: 16 px では印は約 7.5 px の橙の点になり、光の筋は見えない。リボンの左の X と右の柱は見分けられる。32 px では印の筋が見え始める。
- 透かし: リボンの影絵の真ん中に、隙間を空けて印の影絵。

### B 印が主、右下にリボン（`spark-badge`）

Claude の橙の印を大きく置き、右下に VS Code の青いリボンを小さく重ねる。Claude が主で、VS Code が添え物。

- 置き方: 印は幅 720 で、中心 (392, 392)（32〜752）。リボンは 432〜1008 の正方形（幅 576）。リボンのまわりに幅 36 の隙間（透明）。
- 色: 印は `#D97757`、リボンは元の3色。
- 小さい大きさ: 16 px ではリボンが約 9 px になり、3つの中で VS Code の形がいちばん読み取りにくい。印は橙の星形のかたまりに見える。32 px なら両方とも見分けられる。
- 気になる点: 256 px 以上で、リボンの隙間に切られた印の筋の先が小さな橙の欠片として残る（リボンの左上の隙間のあたり）。選ばれたら、隙間か位置を少し直す。
- 透かし: 印の影絵の右下に、隙間を空けてリボンの影絵。

### C 暗い板（`dark-tile`）

暗い灰の角の丸い板の上に、青いリボンと橙の印を A と同じ組み方で置く。今の仮のアイコンと同じく、四角い板の形になる。

- 置き方: 板は 64〜960、角の半径 192（今の意匠の四角と同じ）、色 `#2B2B2B`。リボンは 176〜848（幅 672）。印は幅 400 で、中心 (568, 512)。印のまわりを幅 24 だけ板の色で縁取る。
- 小さい大きさ: 板のおかげで、明るい背景でも暗い背景でも、青と橙がくっきり出る。ただし中の絵は A より小さい（16 px で印は約 6 px）。暗いタスクバー（`#1F1F1F` 前後）では、板の縁がほとんど見えない。
- 透かし: 板は描かない（描くと中の絵と同じ色になって消えるため）。A と同じ組みの影絵。

## 4. 3つの違い（選ぶときの目安）

| | A 中央に印 | B 印が主 | C 暗い板 |
|---|---|---|---|
| 主に見えるもの | VS Code | Claude | 両方（板の上） |
| 16 px での見分けやすさ | 両方とも見える | VS Code がいちばん弱い | 両方とも見える。中の絵は A より小さい |
| 外形 | リボンの形 | 星形とリボンの組み合わせ | 角の丸い四角（今のアイコンと同じ） |
| タスクバーでの目立ち方 | 明るい背景・暗い背景のどちらでも目立つ | 明るい背景では橙が強い | 明るい背景では黒い四角として目立つ。暗い背景では縁が沈む |

## 5. 参考: 橙のリボン（`warm-ribbon`、候補の外）

VS Code のリボンの形を Claude の橙の3色（`#9A4426`・`#C15F3C`・`#D97757`）で塗り、真ん中にクリーム色（`#F5F0E6`）の印を濃い橙（`#7A3520`）で縁取って置いたもの。形は VS Code、色は Claude の、いちばん溶け合った意匠。

ただし、依頼の条件「16・32 px でも両方の要素（VS Code の形、Claude の橙の印）が見分けられること」には合わない。青が無く、印は橙でないため。曹参のテスト（256・32・16 px に青と橙の両方があること）も通らない。このため候補には入れず、描いた見本だけを残した。ユーザーに見せるかどうかはリーダーが決める。

## 6. 書き出し方

```
node scripts/make-icons.mjs --variant <a | b | c | center-spark | spark-badge | dark-tile | warm-ribbon> --out <dir>
node scripts/make-icons.mjs --variant all --preview tasks/2026-11-17-icon
```

`--out` を省くと `assets/` に書く。既定の意匠は、まだ今の仮のアイコン（`current`）のまま。
