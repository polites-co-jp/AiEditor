## 後半（B）: Claude Code の項目（10〜14）と、通信の監査

自分の PowerShell の窓で、リポジトリの直下から次を実行する。`<前半の置き場所>` には、前半で起動した `C:\b\smoke\runs\manual-p2-all-<時刻>` を入れる。

```
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/netaudit.ps1 -Exe C:/b/p2/1.146.0-p2-all/Shuko-win32-x64-1.146.0-p2-all/Shuko.exe -EnvDir C:/b/p0/data/upstream-default -Workspace <前半の置き場所>\ws -Label p2-all-manual-claude -DurationSeconds 600 -Previous records/network-audits/2026-11-15-p2-all-ledger
```

- 台本がエディタを起動し、10分たつと自分で閉じる。起動から30秒ほどで2つのファイルが自動で開くので、そのあとに 10〜14 を行う（合わせて4分ほど）。
- この環境はワークスペースの信頼を切ってあるので、信頼の画面は出ない。台帳の8つの拡張が入っている。Claude Code はログイン済みの `~/.claude/` をそのまま使う。
- 結果は `records/network-audits/2026-11-15-p2-all-manual-claude/audit.md` に出る（日付は実行した日）。
