# 手で確かめる項目（段階 C をまとめた版。`1.146.0-p5-c-all-r2` の関門で作った）

- 作成: 大岡越前守、2026-11-16
- **行うのは、C-1 を直した次の版**。r2 は自動の関門で C-1 が不合格（`gate-C-1-ai.md`）なので、この版でユーザーに手を動かしてもらう段ではない。手順の中の場所・commit は r2 の値で書いた。次の版では、版の名前の所を読み替える
- 元の形: `records/phase2/manual-checks-p2-all.md`（1〜14 はそのまま使う。下の「C の項目」を足す）
- 自動の関門の結果: `gate-p5-c-all-r2.md`（同じフォルダ）
- ここに挙げるのは、各単位の台本 `tests/removals/c*-gate-script.md` の「関門の起動の確かめ」のうち、画面を見て操作しないと分からない項目。自動のスモーク・absent・監査で見られた項目は除いた

## 起動のしかた

前半（画面の項目）は試験用の置き場所で起動する（普段使いのデータには触れない）。

```
node tests/smoke-launch.mjs --build E:/develop/self/Team/projects/ai-editor/tmp/b/p2/1.146.0-p5-c-all-r2/Shuko-win32-x64-1.146.0-p5-c-all-r2 --label manual-p5r2 --mode built
```

後半（Claude Code の送信と通信の監査）は `manual-checks-p2-all.md` の後半と同じ。`-Exe` をこの版の `Shuko.exe` に、`-Label` を `p5r2-manual-claude` に、`-Previous` を `records/network-audits/2026-11-16-p5r2-ledger` に替える。

## p2-all の手順書の 1〜14

`records/phase2/manual-checks-p2-all.md` のとおり。この版での違いは次の2つ。

- 9（Claude Code のパネル）: C-1 で本家のチャットを消したので、アクティビティバーやセカンダリサイドバーに本家のチャットのアイコンは無いのが正しい。Claude のアイコンとパネルは出る。
- 13（差分ビューで採否）: 採否はコメントの部品（`contrib/comments`。C-1 で残した）で出る。C-7 でパンくずを消しても、差分ビューの上の帯が崩れないこと。
